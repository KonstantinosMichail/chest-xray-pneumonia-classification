# Chest X-Ray Pneumonia Classification

Image analysis and machine learning project using chest X-ray images to classify normal and pneumonia cases.

## Project Overview

- Dataset exploration and visualization
- Image preprocessing
- Classical machine learning
- Deep learning
- Model evaluation and confusion matrices

## Dataset

Chest X-Ray Images (Pneumonia) dataset from Kaggle.

## Tools

Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow/Keras
